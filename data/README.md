# Data

Place local datasets or prepared feature files in this folder during development.

## Important

Raw datasets should generally **not** be committed to GitHub because they may be large or subject to dataset license restrictions. The `.gitignore` file is configured to keep this folder's instructions while excluding local data files.

Document the following here once the dataset is finalized:

- Dataset name and official source
- Categories used in experiments
- Train/test split policy
- Image preprocessing steps
